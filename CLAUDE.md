# Everything In Hours website

Marketing site for the Everything In Hours digital marketing agency.

**All work must follow [RULES.md](RULES.md)**: responsive rules, brand colors/logo/type, Gen Z design rules, a11y/SEO and performance. Read it before changing anything.

@RULES.md

## Commands
- `npm run dev`: local dev server
- `npm run build`: production build (must pass before shipping)
- `npm run preview`: preview the production build

## Brand assets
Source files live in `../Manoj --- SS EIH/`. Web-ready copies are in `public/brand/` (processed by `scripts/prepare-brand.mjs`). Never redraw or recolor the logo.
